Dashboard Ambiental DCCRIA

Esta página corresponde a la aplicación web Dashboard Ambiental DCCRIA / Dashboard de Denuncias DCCRIA, utilizada internamente por el personal autorizado de DCCRIA.

Política de privacidad

Esta aplicación accede únicamente a datos almacenados en una hoja de cálculo de Google (Google Sheets) propiedad de DCCRIA, con el único fin de mostrar esa información a las personas autorizadas por el administrador del sistema. El acceso se otorga exclusivamente compartiendo la carpeta o el archivo correspondiente en Google Drive.

La aplicación no almacena datos fuera de Google Drive/Sheets, no comparte información con terceros, y no utiliza los datos para ningún fin distinto al de mostrarlos en el dashboard a las personas autorizadas.

Para cualquier consulta sobre esta política, contactar a: jgrequenac@gmail.com
